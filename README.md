# IT Serwis Opole

Nowoczesna, responsywna strona lokalnego serwisu IT. Projekt jest samodzielny i nie wymaga instalowania zależności.

## Podgląd

Uruchom lokalny serwer w tym katalogu, np. `python -m http.server 4173`, a następnie otwórz `http://localhost:4173`.

## Pliki

- `index.html` — treść i struktura strony
- `styles.css` — wygląd, animacje i responsywność
- `script.js` — menu mobilne, sticky navbar i animacje przy przewijaniu
